# eHKAR Task — Offline Task Manager & Reminder App

A fast, modern, 100% offline-first Android task management and exact-alarm reminder application built with **Kotlin** and **Jetpack Compose** by [eHKAR Software](https://ehkar.com).

## ✨ Key Features
- **100% Offline-First Storage:** All tasks, notes, and schedules are saved locally on your device using Room Database—no internet or account required.
- **Exact-Time Task Alarms:** Set scheduled reminders that ring on time even when the app is closed or your screen is locked, with one-tap deep linking straight to the task.
- **Smart Filtering & Sorting:** Filter tasks by status (All, Open, Done), priority (High, Medium, Low), or category (Work, Personal, Urgent), and sort by Smart Priority or Due Date.
- **Fast Gesture Controls:** Swipe right to complete a task, swipe left to delete with instant Undo support, and toggle haptic feedback in Settings.
- **Modern Material 3 UI:** Clean dark-mode interface crafted with Jetpack Compose.

## 🛠 Built With
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose & Material 3
- **Architecture:** MVVM + Clean Repository Pattern
- **Local Persistence:** Room Database & Jetpack DataStore
- **Dependency Injection:** Dagger Hilt
- **Alarms & Notifications:** `AlarmManager` (`setAlarmClock`) & Foreground `shortService`
